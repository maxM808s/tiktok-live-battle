# Connect TikFinity

1. Install/open [TikFinity Desktop](https://tikfinity.zerody.one/landing/) on your broadcast PC and connect it to your TikTok LIVE.
2. Open your game's dashboard. For a private LIVE Studio Link source, use the dashboard opened by the [Windows launcher](OVERLAY.md).
3. Assign gifts and points. Under **LIVE**, enter a stream session label and keep it unchanged for reconnects of the same broadcast.
4. Click **Connect TikFinity**, then **Start battle**.
5. Send a small mapped gift and check the resulting points. Streak gifts count when they finish.

A connected indicator means TikFinity Desktop is reachable; it does not prove TikTok is LIVE. Use one dashboard and disconnect when finished.

## If it does not work

- Check that TikFinity Desktop is running on this same PC and connected to the intended channel.
- Check that the battle is started and the gift is mapped. Finish any gift streak before expecting points.
- Read the dashboard's connection message and try **Reconnect**. If another dashboard owns the connection, close or disconnect it first.
- If the browser requests local-network access, allow it only for this trusted game. Do not disable browser security or expose local ports to the internet.
- If saving fails, resolve the storage error and inspect scores before reconnecting. Unsaved gifts are not automatically recovered.
- Do not clear replay history or change session labels to force an event to score. Disconnect before restoring a backup.

TikFinity's free plan has feature limits; check current terms in its app. No unlimited-service promise is made.
